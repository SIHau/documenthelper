# 公文小幫手（documenthelper）

協助撰寫公文的工具（不使用 AI，以結構化表單與規則為主）。目標是符合《文書處理手冊》格式，並在後續里程碑支援電子公文交換（ODF + DI）。

## 開發

```bash
npm install
npm run dev     # 開發伺服器
npm test        # 單元測試
npm run build   # 型別檢查並建置
```

## 目前進度：M1、M2、M3、M5（M4 暫緩，待取得官方規格）

- 函、書函的結構化表單
- 說明／辦法的多層級分段與自動編號（一、(一)、1、(1)、甲、(甲)）
- 民國日期顯示
- 即時預覽、瀏覽器列印／另存 PDF
- 草稿自動儲存於瀏覽器（localStorage）

### M2 匯出

- **ODT**（ODF 1.2，自行產生，不依賴外部服務）與 **DOCX**，兩者共用同一份中介版面（`src/export/layout.ts`），內容一致
- **PDF**：目前透過瀏覽器「列印／另存 PDF」，已設定 A4 版面
- 簽名字體 Yuji Boku 在檔案中以字體名稱引用，開啟檔案的電腦需安裝該字體，否則會改用預設字體

### M3 文種、檢查與用語庫

- 文種：函、書函、公告、開會通知單、簽（欄位與段落標題由 `src/model/docTypes.ts` 設定）
- 預覽與匯出共用同一份版面資料，所見即所得
- **檢查**（`src/rules/`，純規則、不使用 AI）：必填欄位、主旨期望語與長度、行文方向與期望語是否相符、附件前後一致、西元年份、口語詞、分項標點
- **用語庫**（`src/data/phrases.ts`）：主旨句型、引敘、過渡、結尾、依行文方向分類的期望語，點選即插入游標處
- 檢查規則與用語為依常見公文慣例整理，尚未逐條對照官方手冊，可在上述檔案調整

### M5 通訊錄、歷史稿件與範本

- 資料存於瀏覽器 IndexedDB（`src/db/`），不上傳任何伺服器
- **通訊錄**：新增、編輯、搜尋；CSV 匯入匯出（Excel 可開，同名者更新）。發文機關／受文者輸入時可從通訊錄挑選並帶入代碼、地址等；正本、副本可用選單加入。機關代碼由使用者自行維護，未內建官方代碼表
- **歷史稿件**：儲存、開啟、複製為新稿、刪除，可依關鍵字與文種搜尋；有未儲存變更時，開啟其他稿件前會確認
- **範本**：將目前稿件存為範本；內建 6 個範本（以「○」標示待填處，檢查頁籤會提醒）
- **備份與還原**：一次匯出／還原稿件、範本與通訊錄（JSON）。資料只在本機，請定期備份

## 路線圖

M2 ODT/PDF 匯出 → M3 格式與用語檢查、更多文種 → M4 電子交換 DI 匯出（需官方 DTD 規格） → M5 通訊錄與歷史稿件 → M6 桌面版（Tauri）
