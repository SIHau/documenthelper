# 公文教學資料（Markdown 版）

這些是使用者提供的雲端硬碟資料夾「公文編輯筆記」裡的教學文件，轉成 Markdown 方便搜尋與引用。AI 撰寫公文時，**格式與用語以這些資料為準**；`writing-guide.md` 是整理後的重點，`dh check` 的規則也是依這些資料寫成，訊息裡標示的出處都對應這裡的檔案。

## 怎麼用

- 不確定寫法時先用 `grep -n "關鍵字" references/source/*.md` 找原文，再引用（說明修正理由時請標出處，例：「依文書處理手冊第十八點」）。
- 檔案內以 `<!-- 第 N 頁 -->` 標示原 PDF 的頁碼。
- 原 PDF 是掃描圖片的頁面以 OCR 辨識，會有錯字，檔案裡有「（此頁為圖片，以下為 OCR 辨識結果）」的提示；重要規定請對照原檔，不要照抄 OCR 的亂碼。
- 版面圖、章戳位置與印信這類圖形資訊沒有轉進來；版面規格看 `政府文書格式參考規範_105年4月.md` 的文字說明。

## 索引（使用者原始的重點摘要）

使用者在雲端硬碟「索引」裡標示的重點：

- 《函的概念與範例》第 3～5 頁：函文用字。
- 《公文寫作》第 9～18 頁：公文結構、用語。
- 《中央行政機關法制作業應注意事項》全：法令編寫結構、格式。
- 《公文法律用字》全：法律用字對照表（善用搜尋）。
- 《實務常見公文的文言語彙》全。

線上工具（供使用者自行查閱）：文書編輯共通服務平台（edit.good.nat.gov.tw）、國家文官學院《公文撰作解析電子書》（內容最完整）、司法院裁判通俗化用語彙整表與法律用字用語統一表、司法院書狀範例；另有 Google 文件使用標楷體匯出 PDF 變成正黑體的解決方式。
