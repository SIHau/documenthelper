# 公文撰寫指引

這些是常見的公文寫法與公文小幫手檢查規則的依據；**不是官方標準**，使用者機關有自己的慣例時以機關為準。

## 主旨

- **一段、一句話說完**，不分項、不換行；建議力求簡明（約 60 字內，超過會有「建議」提醒）。
- 先寫事由，再接期望語；結尾用句號。
  - 函、書函：`檢送○○一案，請查照。`、`有關○○一案，復如說明，請查照。`、`函請貴單位協助○○一案，請查照惠復。`
  - 簽：`為辦理○○，簽請核示。`
  - 公告：`公告○○。`
- 主旨寫完就能讓人知道「是什麼事、要對方做什麼」，細節放說明。

## 期望語（依行文方向）

| 行文方向 | 對象 | 常用期望語 | 不宜使用 |
|---|---|---|---|
| 上行 | 對上級機關 | 請鑒核、請核示、請鑒察、請核備、請核定、請准予備查 | 請查照、請察照、請照辦、請惠允 |
| 平行 | 對同級機關 | 請查照、請查照轉知、請查照辦理、請惠予協助、請惠復、請同意 | 請鑒核、請核示、請照辦、請依限辦理 |
| 下行 | 對下級機關 | 請查照、請照辦、請查照轉知、請依限辦理、請辦理見復、請確實辦理 | 請鑒核、請核示、請鑒察 |

`dh phrases 上行` 可列出該方向的用語。

## 說明

- 第一項通常**引敘來文或依據**：`依據貴單位115年11月1日○○字第○○○號函辦理。`、`復貴單位○年○月○日○○字第○○○號函。`、`依○○法第○條規定辦理。`
- 接著寫理由、辦理情形與細節，分項表達；每一項寫完整一句，以「。」「；」「：」結尾（結尾缺標點會有「建議」提醒）。
- 需要對方回復或配合時，寫明期限：`請於中華民國115年11月20日前回復。`，並在稿件填 `limit`。
- 結尾可用：`如有疑義，請洽承辦人。`、`敬請惠予配合。`、`併請查照。`

## 分項層級

一、→ (一) → 1、→ (1) → 甲、→ (甲)。同一層級的項目用同一種編號；需要細分才降一層，不要為了只有一項而硬分層。編號由程式處理，`text` 只寫內容。

## 日期與數字

- 內文用**民國年**：`中華民國115年11月20日`、`115年11月20日`；使用 2026 之類的西元年份會被提醒。西元年減 1911 即民國年。
- 稿件欄位 `date`、`limit` 一律用 `YYYY-MM-DD`。

## 附件

- 內文或主旨提到「附件」「檢附」「檢送」「隨函」，要在 `attachments` 寫明附件名稱與份數；反過來，附件欄有內容而內文沒提到也會被提醒。
- 沒有附件就留空，不要硬填。

## 用語

避免口語詞，改用公文用語（檢查會列出）：

| 口語 | 公文用語 |
|---|---|
| 然後 | 並、續 |
| 可是 | 惟、但 |
| 所以 | 故、爰 |
| 還有 | 暨、以及 |
| 因為 | 因、緣 |
| 大概 | 約、概 |
| 謝謝 | 申謝、致謝 |
| 麻煩 | 煩請、惠請 |
| 馬上 | 立即、即刻 |

## 簽名與機關資料

- `signature` 填頭銜與姓名即可，字體預設 Yuji Boku；不需要時 `enabled: false`。
- 機關名稱、地址、承辦人、電話、電子信箱一律用使用者提供的資料；不知道就留空，不要猜。

## 交付前自我檢查

1. `dh check` 沒有錯誤、沒有「注意」（或已逐項向使用者說明）。
2. 沒有殘留的「○」。
3. 主旨結尾有期望語且與行文方向相符；說明第一項有依據。
4. 日期是民國年、金額與份數與使用者提供的一致。
5. 附件欄與內文一致。
6. `dh preview` 的內容與使用者要求相符。
